📱 카메라 사용 방법

갤럭시 기본 브라우저(삼성 인터넷)나
크롬에서 카메라를 쓰려면
인터넷 주소(https://)로 접속해야 합니다.

추천 · 가장 쉬움
🌐 GitHub Pages로 무료 배포
파일을 인터넷에 올리면 자동으로 https:// 주소가 생겨요.
회원가입 → 파일 업로드 → 링크 접속만 하면 끝!
1

github.com 접속 → 무료 회원가입

2

로그인 후 우상단 ＋ → New repository 클릭

3

이름 아무거나 입력 → Public 선택 → Create repository

4

uploading an existing file 클릭 → timemark-camera.html 파일 끌어다 놓기

5

Commit changes 버튼 클릭

6

Settings → Pages → Source: main 선택 → Save

7

잠시 후 아래 주소로 접속!

https://[내아이디].github.io/[저장소이름]/timemark-camera.html
대안 · PC 있을 때
☁️ Netlify Drop (드래그 앤 드롭)
PC에서 app.netlify.com/drop 접속 후
html 파일을 그냥 끌어다 놓으면 즉시 https:// 링크 생성!
1

PC 크롬에서 app.netlify.com/drop 접속

2

timemark-camera.html 파일을 페이지에 드래그

3

자동 생성된 https:// 링크를 갤럭시로 열기
